# Перевірка BLADE

Дата: 22 жовтня 2026 року.

## Автоматичні перевірки

- `npm run check`: синтаксис серверної та клієнтської частин.
- `npm test`: 10 перевірок, 10 пройдено, 0 помилок.
- Вісім одночасних запитів на один інтервал: один успішний, сім конфліктів.
- Доступність: перетини, стики, різна тривалість, робочі дні та мінімальний час до візиту.
- Перевірка дати та часового поясу Europe/Kyiv.
- Ізоляція записів між демонстраційними відвідувачами.
- Заборона перенесення та зміни чужих записів.
- Відхилення запитів з іншого Origin.
- Невдале перенесення зберігає попередній запис; успішне звільняє старий інтервал.
- Скасування звільняє інтервал; завершений візит зберігає зайнятий час.
- Зміна цін і тривалості не переписує попередні записи.
- Записи та налаштування зберігаються після перезапуску сервера.
- У режимі реальної студії перевірено пароль адміністратора, заборону адміністративних дій клієнту та відсутність чужих контактів у клієнтській відповіді API.

## Ручна перевірка

- У браузері локально: послуга → майстер → час → тестові контакти → успішний запис.
- Створений запис відображається в календарі кабінету.
- У браузері локально: перенесення з 10:00 на 11:00 та скасування з підтвердженням; обидві дії збережені й відображені у списку.
- Опублікований сайт: https://blade.92-5-167-222.sslip.io/ — HTTPS, відповідь головної сторінки та `/api/health` успішні.
- У браузері на опублікованому сайті: послуга → Артем → 11:00 → тестові контакти → підтвердження. Візит відображається у календарі кабінету.
- На опублікованому API: створення, перенесення, скасування, звільнення часу та ізоляція нової сесії пройшли перевірку.
- Контейнер примусово перезапущено під час перевірки: запис залишився в SQLite volume, підписаний cookie зберіг доступ до нього.
- Docker на Oracle ARM64: контейнер має стан `healthy`, автоматичний перезапуск `unless-stopped`.
- GitHub Actions: синтаксис, 10 тестів та складання Docker-образу успішні.
- Мобільну компоновку візуально перевірено у вікні 390 × 844 через локальний iframe-предперегляд. Автоматичне вимірювання внутрішнього iframe недоступне через обмеження API браузера; перевірка на фізичному телефоні не проводилася.

## Обмеження

- Відвідувачі демо керують лише власною пісочницею.
- SMS, email, платежі та зовнішні нагадування не підключені.
- Сервіс не підтверджує реальний візит до барбершопу.
- Надсилання нагадувань і перевірка на фізичних мобільних пристроях не проводились.
