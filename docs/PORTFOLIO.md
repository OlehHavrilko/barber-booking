# BLADE — онлайн-запис до барбершопу

## Завдання

Створити зручний запис без дзвінків: клієнт обирає послугу, майстра та вільний час, а команда бачить візит у календарі.

## Рішення

Вебзастосунок з українським адаптивним інтерфейсом, серверним розкладом, перенесенням і скасуванням візитів. Адміністративний кабінет поєднує календар трьох майстрів, статуси, статистику та налаштування послуг.

Захист від подвійного бронювання реалізовано у транзакції бази даних. Ціна й тривалість зберігаються на момент запису, тому наступні зміни прайсу не змінюють умови попереднього візиту.

## Технології

Node.js 24, SQLite, JavaScript, HTML/CSS, Docker Compose, Caddy, Oracle Cloud VPS. Без зовнішніх npm-залежностей.

## Що показати в демо

1. Обрати стрижку, майстра та час.
2. Заповнити тестові контакти та підтвердити запис.
3. Відкрити календар кабінету й знайти цей візит.
4. Перенести візит та перевірити звільнення старого часу.
5. Змінити ціну послуги; попередній запис збереже початкову суму.

## Статус кейсу

Самостійний демонстраційний проєкт для портфоліо. Бізнес, майстри та відвідувачі вигадані. Не видається за роботу для реального замовника. Кожен відвідувач публічного демо отримує власну ізольовану студію. SMS, email та платежі не інтегровані.
